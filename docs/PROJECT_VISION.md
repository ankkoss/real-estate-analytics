# Real Estate Intelligence Platform

## Project Overview

Real Estate Intelligence Platform — это аналитическая платформа, предназначенная для автоматического сбора, хранения, обработки и анализа данных рынка недвижимости.

Проект моделирует архитектуру современной Data Platform, которая может использоваться агентствами недвижимости, аналитиками, инвесторами и девелоперами.

Основная цель проекта — продемонстрировать навыки проектирования промышлененного Data Engineering решения, а не только написать ETL-скрипт.

---

# Goals

Проект должен:

- автоматически получать данные из внешних источников;
- хранить историю изменений объявлений;
- очищать и валидировать данные;
- строить аналитические витрины;
- предоставлять API;
- отображать интерактивную аналитику;
- быть масштабируемым.

---

# Target Audience

- аналитики рынка недвижимости;
- агентства недвижимости;
- инвесторы;
- девелоперы;
- рекрутеры и технические интервьюеры.

---

# Business Problems

Платформа должна отвечать на вопросы:

- Где быстрее всего растут цены?
- Какие районы становятся дешевле?
- Какие квартиры переоценены?
- Где самая высокая стоимость квадратного метра?
- Как менялась цена конкретного объявления?
- Какие квартиры продаются быстрее остальных?

---

# Main Features

- автоматический сбор данных;
- ежедневное обновление информации;
- хранение полной истории;
- аналитические отчёты;
- интерактивные графики;
- карта цен;
- API;
- мониторинг ETL.

---

# Non-functional Requirements

- модульная архитектура;
- высокая читаемость кода;
- возможность масштабирования;
- логирование;
- тестирование;
- контейнеризация;
- воспроизводимость окружения.

---

# Success Criteria

Проект считается успешным, если:

- данные автоматически обновляются;
- вся история сохраняется;
- архитектура разделена по слоям;
- API предоставляет аналитику;
- Dashboard отображает ключевые метрики;
- новый источник данных можно добавить без изменения существующей логики.
